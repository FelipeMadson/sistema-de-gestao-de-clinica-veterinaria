[![Release](https://img.shields.io/badge/release-v1.0.0-green.svg)](https://github.com/FelipeMadson/sistema-de-gestao-de-clinica-veterinaria/releases)

Motor corporativo de gestão para clínicas e hospitais veterinários. Gerencia prontuários eletrônicos, agendamento de consultas com detecção de conflitos de horários e controle de vacinação preventiva.

## Funcionalidades

- **Cadastro de Pacientes e Tutores**: Suporte para múltiplas espécies (caninos, felinos, aves e animais exóticos).
- **Agendamento Inteligente**: Prevenção algorítmica de consultas sobrepostas para o mesmo médico-veterinário ou animal.
- **Prontuário Médico Unificado**: Histórico contínuo de diagnósticos, tratamentos e prescrições.
- **Monitor de Vacinação**: Alertas automáticos de vacinas vencidas ou com renovação pendente.

## Execução e Testes

```bash
npm install
npm run build
npm test
```
